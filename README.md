# Laroche Cafe — نسخة برابط واحد

هلق صارت 2 نشرة بس (بدل 3):

```
laroche-single/
├── backend/        → السيرفر (ينشر لحاله متل قبل)
├── index.html      → التطبيق كله: زبون + نادل بنفس الرابط
└── config.js       → فيه رابط الـ backend
```

## الروابط جوا الموقع الواحد
- `/#/` → صفحة اختيار الطاولة (هيدي أول شي بيطلع)
- `/#/table/7` → صفحة الطاولة رقم 7 (هيدا يلي بيروح فيه QR)
- `/#/waiter` → لوحة النادل (فيها زر صغير بأسفل يسار الشاشة بصفحات الزبون، شكله أيقونة شخص صغيرة وباهتة)
- `/#/admin-print` → صفحة طباعة الـ QR (وصول ليها من جوا لوحة النادل نفسها)

## خطوات النشر
1. انشر `backend/` لحاله (متل قبل، ع Render مثلاً) وخد رابطه.
2. افتح `config.js` وحط فيه رابط الـ backend.
3. انشر `index.html` + `config.js` سوا كموقع واحد (GitHub Pages / Netlify / Vercel).
4. رابط الموقع الواحد يلي طلعلك هو نفسه يلي بتحطه بالـ QR على الطاولات (`رابطك#/table/1` لحد `25`)، ونفسه يلي بتفتحه لتوصل للوحة النادل عبر الزر الصغير أو بإضافة `#/waiter` آخر الرابط مباشرة.

## شنو يترفع ع GitHub بالظبط
```
backend/server.js
backend/package.json
backend/.gitignore
index.html
config.js
README.md
```
(نفس المنطق السابق: `node_modules` و `data.json` ما بترفعهم، موجودين بـ `.gitignore`)

## ملاحظة أمان بسيطة
زر دخول النادل صغير وباهت قصدياً بس مش محمي بكلمة سر — أي حدا يعرف يضغط عليه أو يكتب `#/waiter` بالرابط بيوصل للوحة. إذا بدك حماية أقوى (كلمة مرور بسيطة قبل ما تفتح اللوحة)، قلي وضيفها.
